01 · Workflow productivity

AutoMind AI — Task Workspace

Try adding a task, changing its status and tracking a small office workflow.

View demo code first
const tasks = [];
function addTask(title, priority) {
  if (!title.trim()) return;
  tasks.push({ title, priority, status: "Pending" });
  renderTasks();
}
function completeTask(index) {
  tasks[index].status = "Completed";
  renderTasks();
}
