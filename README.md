# Zulqarnain Khan Jadoon — Portfolio Website

This repository contains the source files for the portfolio website published through GitHub Pages.

## Website Pages

- **[Portfolio homepage](https://zulqarnainjadoon99.github.io/)** — the primary portfolio entry page.
- **[Projects directory](https://zulqarnainjadoon99.github.io}/projects.html)** — a directory of 13 repository-backed projects, with additional browser-only previews for selected concepts.
- **[Digital Universe](https://zulqarnainjadoon99.github.io}/universe.html)** — a secondary landing page featuring selected work, skills, and contact sections.

## Main Source Files

| File | Purpose |
|---|---|
| `index.html` | Primary portfolio homepage |
| `projects.html` | Project directory, repository links, visual cards, and illustrative browser previews |
| `universe.html` | Secondary portfolio landing page |
| `archive/original-first-portfolio-index5.html` | Archived original homepage snapshot |

The browser previews in `projects.html` are illustrative front-end demonstrations. They do not replace or execute the full server-side Python or C++ applications linked from the repository cards.
